Building My First HTML Website

This tutorial explains the HTML concepts used in my website and the purpose of each section of code.

1. HTML Document Structure

<!DOCTYPE html>
<html lang="en">

The DOCTYPE declaration tells the browser that the document uses HTML5. The html element is the container of the webpage.

2. Head Section

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
    content="width=device-width, initial-scale=1.0">

    <title>Amars Page</title>
</head>

The head section contains information about the webpage.

  • UTF-8 supports special characters.
  • Viewport makes the site responsive.
  • Title appears in the browser tab.

3. Background Image Styling

<style>
body {
    background-image: url("settings.JPG");
    background-size: cover;
    background-repeat: no-repeat;
    background-position: center;
}
</style>

This CSS adds a background image, stretches it across the page, prevents repetition, and centers it.

4. Main Heading

<h1>Welcome to My Website</h1>

The h1 element creates the main heading of the page.

5. Navigation Links

<a href="index.html">Home</a>
<a href="index2.html">Schedule</a>
<a href="about.html">About</a>
<a href="Contact.html">Contact</a>

Anchor tags create hyperlinks that allow users to move between pages.

6. Horizontal Rule

<hr>

The hr element creates a horizontal line used to separate content.

7. Miscellaneous Elements

<h1><ins>Introduction</ins></h1>

<p>
This is <b>Web-programming</b> first website
</p>

<p>
<q>Basic Html code implementation</q>
</p>
<abbr title = "learn" > hover </abbr>
<delete>This text is deleted</delete>
<ins>This text is inserted</ins>
<u>This text is underlined</u>
<sub>This text is subscript</sub>
<sup>This text is superscript</sup>

This section demonstrates:

  • Headings
  • Paragraphs
  • Bold text
  • Inline quotations
  • Underlined text
  • Abbreviations with tooltips

In demonstration, the ins tag underlines text. The b tag makes text bold, and the q tag formats inline quotations. The abbr hover tag provides a tooltip when hovered over. The p tag defines paragraphs of text. The delete tag indicates deleted text. The underlined tag underlines text. The subscript tag creates subscript text. The superscript tag creates superscript text.
